# ApexPlanet Cybersecurity Internship – Task 1

## Cybersecurity Fundamentals and Virtual Lab Setup

This repository contains the documentation and practical work completed as part of Task 1 of the ApexPlanet Cybersecurity Internship.

## Objectives
- Understand cybersecurity fundamentals and the CIA Triad.
- Set up a virtual cybersecurity lab.
- Configure Kali Linux and Metasploitable 2.
- Perform network scanning using Nmap.
- Capture and analyze network traffic using Wireshark.
- Demonstrate network communication using Netcat.
- Practice essential Linux commands.

## Lab Environment

| Component | Details |
